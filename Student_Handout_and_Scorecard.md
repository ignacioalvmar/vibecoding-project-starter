Today we will see **one product built with seven tools**: Lovable, Replit, DeepSite, Cursor, Google Antigravity, OpenAI Codex and Claude Code. All of them will work from the same PRD, so you can compare the tools.

You do **not** need an account for every tool. Pick your role per tool:

## The plan for today

1. **Bake-off:** Lovable, Replit and DeepSite get the *same* kick-off prompt. We compare the three results side by side.
2. **Relay:** Cursor, Antigravity, Codex and Claude Code each add one feature to the same GitHub repo:
   - Cursor: design-token refactor (THI colors from DESIGN.md)
   - Antigravity: German / English toggle, verified by its browser agent
   - Codex: accessibility audit and fixes, then a code review
   - Claude Code: unit tests for the calculator and a screenshot check

**Your quick test for every result:** set 20 prompts/day, model "large", 5 images/week. Correct result: **155.0 Wh** and **58.9 g CO2**. If the tool shows something else, it did not follow the PRD.
